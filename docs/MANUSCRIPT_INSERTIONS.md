# Manuscript insertions

## Data and Software Availability

The data supporting the conclusions of this study are provided in the article
and its Supporting Information. Prepared structures, representative NAMD and
MM/GBSA configuration files, analysis scripts, and one-frame example
trajectories for the apo, Z944-bound, and mZ944-bound systems are openly
available at Zenodo at [ZENODO DOI]. The source code is also maintained at
[GITHUB REPOSITORY URL], and the version used for this study is archived as
release v1.0.0 in Zenodo. Because of their large file sizes, the complete
production trajectories are available from the corresponding author upon
reasonable request.
